# 老人ホーム出店専用アプリ「孫LOVE」

有料老人ホームの出店を、**不動産仕入れ → 法規制確認 → 役所申請 → 介護事業者採用 → 入居者獲得 → 内装工事 → 開業** まで一元管理するWebアプリです。
関東エリア（1都6県）を都道府県 → 市区町村 → 区の単位でクローズして確認できます。

- 基本無料で運用（Flask + JSONファイル保存。DB不要。地図は国土地理院タイル、ジオコーディングも国土地理院API）
- 物件は **すべて同じ統一フォーマット** で保存。個別の内容はメモ・報告・書類リンクに記載
- Slack 通知（登録 / ステータス変更 / 内見・現調報告 / 予定更新 / 毎朝のリマインド）
- Google ドライブ・Google カレンダー・Google スプレッドシート連携。ZENRIN 地図はキー設定で切替

## 育成ゲーム要素（パートナー・レベル・クエスト）

- **パートナー選択**: 初回ログイン時に4人のキャラ（ルカ🐺 物件ハンター / ハルト施設長🐰 申請担当 / コタロウ🐻 採用担当 / モモ🐶 入居者獲得担当）から選択。画面右下に常駐し、期限超過・直近の予定・今いる画面や物件の工程に合わせて吹き出しで話します（クリックで次のセリフ）。
- **レベル・経験値**: 物件登録 20 / ステータス更新 50 / タスク完了 10 / 報告 30 / 営業先追加 15 / 自動調査 15 XP。レベルアップ演出と称号（見習い出店担当 → 出店プランナー → … → 孫LOVEマスター）。
- **クエストボード**: ダッシュボードで物件ごとに7工程の進み具合をトラック表示。工程ごとに担当キャラが付き、採用（ジョブメドレー等）や斡旋先検索へのリンクを表示。
- **キャラ画像**: ギルド設定から各キャラの元画像（全身・白背景）をドロップでアップロード。白背景は自動で透過処理。「表情を生成」で笑顔・応援・驚き・考え中・心配・眠いのバリエーションを画像生成AI（Vertex AI Gemini 画像モデル。`setup-cloudshell.sh` が有効化）で作成し、会話内容に合わせて表情が切り替わる。名前も変更可
- **デザイン**: ダークファンタジー／MMORPG風のギルドホールUI（オーロラ背景・光の粒子・金の装飾枠・RPG風会話ボックス・羊皮紙調のワールドマップ・レベルHUD）

## 物件・エリア選定の支援

- **候補スコア（0-100）**: 「介護者・入居者が取れそうな市に近く、坪単価が低い」物件を高評価。価格（坪単価の相対順位 40%）× 需要（市区町村の要介護認定者数/65歳以上人口 35%）× アクセス（3km以内のケアマネ事業所・病院・介護施設数 25%）。売買物件は価格を20年で月額換算して比較。
- **エリア比較**: 統計データ画面に、市区町村ごとの「需要 ÷ 他社施設数」「候補物件の平均坪単価」ランキング。行をクリックするとマップでその市にクローズ。
- **現地リスク自動調査**: 物件の座標から、国土地理院 標高API・J-SHIS 表層地盤・重ねるハザードマップ（洪水想定最大/計画規模・浸水継続時間・家屋倒壊・土砂災害3種・津波・高潮）をワンクリックで判定。浸水想定区域なら「避難確保計画が必要」などの注意を表示。
- **営業先（入居者獲得）**: 物件ごとに居宅介護支援事業所・病院・紹介会社への「未訪問 → チラシ配布済 → 訪問済 → 斡旋依頼済 → 紹介あり」を管理。3km以内の登録施設から一括追加。

## ローカル起動

```bash
cd mago-love
pip install -r requirements.txt
cp .env.example .env   # ADMIN_EMAIL を自分のメールに
python app.py          # http://localhost:5050
```

`GOOGLE_CLIENT_ID` 未設定時は開発用ログイン（ユーザー選択）になります。本番では必ず設定してください。

## 環境変数

| 変数 | 必須 | 説明 |
| --- | --- | --- |
| `ADMIN_EMAIL` | ○ | 初回起動時に管理者として登録するメール |
| `GOOGLE_CLIENT_ID` | 本番○ | Google ログイン（招待制）。[設定手順](../docs/google-login-setup.md) |
| `MAGO_DATA_DIR` | 本番○ | データ保存先（永続ディスク）。未設定なら `./data` |
| `SECRET_KEY` | | セッション署名キー。未設定なら自動生成して保存 |
| `SLACK_WEBHOOK_URL` | | Slack Incoming Webhook（画面からも設定可） |
| `APP_URL` | | 通知内リンクのベースURL |
| `CRON_TOKEN` | | 日次ダイジェスト `/api/cron/digest?token=` の保護 |
| `ANTHROPIC_API_KEY` | | 任意。PDF取込のAI構造化を有効化 |
| `TRUST_PROXY` | 本番○ | リバースプロキシ配下（Render / Cloud Run）で `1` |

## 連携の設定

### Slack
1. Slack で「アプリ → Incoming Webhook」を追加し、通知チャンネルの Webhook URL を取得
2. アプリの **設定・連携 → Slack通知** に貼り付けて「テスト送信」
3. 毎朝のリマインドは `GET /api/cron/digest?token=…` を無料の cron（[cron-job.org](https://cron-job.org) か本リポジトリの GitHub Actions `mago-love-digest.yml`）から叩く

### Google ドライブ
- 物件ごとに「Driveフォルダ URL」を設定し、稟議書・収支・図面などの **リンクを書類として登録**（無料・設定不要）
- `GOOGLE_CLIENT_ID` と「Google API キー（Picker API 有効）」を設定すると、**Driveから選択** と **Driveにフォルダ作成** が使えます（ブラウザ側 OAuth。サーバーに秘密情報は置きません）

### Google カレンダー / スプレッドシート
- 設定で ICS トークンを発行し、`/api/export/calendar.ics?token=…` を Google カレンダーの「URLで追加」に登録
- 物件一覧の「CSV」をスプレッドシートにインポート

### ZENRIN 地図
- ZENRIN Maps API を契約後、設定の「ZENRIN タイルURL」にラスタタイルURLを設定すると地図の既定レイヤになります。未設定時は国土地理院（淡色 / 標準 / 航空写真）と OpenStreetMap を使用（無料）

### 統計データ（人口など）
- e-Stat や自治体サイトのCSVを「都道府県, 市区町村, 指標…」の形にして取込。市区町村を選ぶと地図右下に表示

### PDF 取込
- テキスト付きPDFは自動抽出（物件名・住所・賃料・面積・構造・駅など）
- スキャンPDFは Google ドライブの「Googleドキュメントで開く」(OCR) などの無料ツールでテキスト化して「テキスト貼り付け」

## データ

`MAGO_DATA_DIR` 配下に JSON で保存されます。

- `properties.json` 物件（統一フォーマット + タスク + 報告 + 書類 + 履歴）
- `pois.json` 周辺施設 / `stats.json` 統計 / `users.json` / `settings.json`
- `uploads/` 取り込んだ PDF

`data/kanto_municipalities.json` は関東1都6県の市区町村（政令市の区含む 360件）と中心座標のマスタです。
