# 初回市場調査（2026-09-28）

## 0. 調査方法と制約

- **X の投稿データは未取得**。X の公開ポストは公式 API の検索（読取 $0.005/ポスト）でのみ収集する方針とし、
  X の認証情報が渡されていないため、本セッションでは**公開 Web 上の解説記事・事例**から構造を抽出した。
  画面スクレイピングは X 規約違反のため行っていない。
- 認証情報が揃い次第 `affiliate-bot research --collect --analyze` を実行すると、
  `research_posts` に Views / Likes / Reposts / Replies / Bookmarks / 経過時間 / フォロワー数 を保存し、
  `Views/フォロワー`・`Views/経過時間`・`Engagement/Views` で **小規模アカウントでも異常に成果の高い投稿** を抽出して
  パターン DB に追加する（Sonnet 5 で構造を抽象化。文章はコピーしない）。
- 概算費用: 4 クエリ × 100 ポスト = 400 ポスト読取 ≒ $2 + 著者 ≒ $1〜4。1 回で十分。

## 1. 公開情報から抽出した「伸びる構造」（事実と意見を分離）

| 観点 | 複数ソースで一致した事実 | 意見・未検証 |
|---|---|---|
| メディア | DMM 提供のサンプル動画（非露骨シーン数秒〜）付き投稿はパッケージ画像より表示が多い。1,000 フォロワー未満で数百万表示の事例あり（動画・画像とも） | 60 秒以下が良い／テロップが必要（テロップは DMM 規約上不可） |
| リンク位置 | 本文に外部リンクを置かず**リプ欄にアフィリエイトリンク**（表示数維持・広告臭低減）。X 料金上も本文リンクは 13 倍高い | — |
| 投稿頻度 | 1 日 5〜6 投稿が上限目安。多すぎると表示が減る | 10 投稿/日 |
| アカウント設計 | ジャンル特化（例: 人妻／素人／美脚）でフォロワーが付きやすい。プロフィール画像・ヘッダーは露骨表現不可 | 名前は 3〜5 文字 |
| 文章 | 「有益な情報」を発信しているか。URL だけ・メディアだけの投稿は評価されない。クリックベイトは規約リスク | フックの型: 体験談風／予告風 |
| 時間帯 | 具体的な統計は公開されていない → **バンディットで学習する** | 夜 21〜24 時 |
| 品質シグナル | 高表示投稿は いいね・リプ・ブックマークが多く、ブロック/ミュートが少ない（非フォロワーへの推薦に効く） | — |
| 数値 | 「800 円/CV・CVR 5%・50 クリック/投稿」等は**シミュレーション値**で実測ではない | — |

## 2. 初期パターン分類（Winning Pattern DB のシード。confidence=0.2）

| Pattern ID | カテゴリ | 何が効くと仮定しているか |
|---|---|---|
| P01_actress | 女優訴求型 | 名前検索・ファン層への到達。固有名詞が冒頭にあると検索流入 |
| P02_title | 作品訴求型 | 「どんな体験か」を 1 文で言い切ることでスクロール停止 |
| P03_situation | シチュエーション訴求型 | 情景描写でジャンル層の自己投影を誘う |
| P04_limited | 期間限定訴求型 | 割引率と期限を先頭に置き即時行動を促す（CVR に効く） |
| P05_ranking | ランキング型 | 選択肢を減らして迷いを解消 |
| P06_newrelease | 新作型 | 配信日という客観情報で常連層に刺さる |
| P07_discovery | 発掘作品型 | レビュー数少・評価高の作品は競合が少ない |
| P08_video | 動画主導型 | 文章最小＋サンプル動画。表示数の主力 |
| P09_short | 短文型 | 20〜40 字＋画像。生成コスト最小 |
| P10_review | レビュー型 | 実データ（平均・件数）は信頼を作る。捏造しない |
| P11_story | ストーリー型 | あらすじ風 2〜3 行で物語性 |
| P12_price | 価格訴求型 | 低価格帯はクリック→購入の摩擦が小さい |

カテゴリは調査結果に応じて `research --analyze` が追加（R_ プレフィックス）し、
成績の悪いものは `patterns.decay_stale()` が自動で減衰・降格する。

## 3. 調査から得た設計上の判断

1. **メディア（画像/動画）は本文、リンクはリプ**を既定にする（`LINK_IN_REPLY=true`）
2. **1 日 5 投稿**を初期値にし、バンディットの報酬（表示あたり利益）で増減を週次判断する
3. 投稿時間は固定せず 8 枠 × Thompson Sampling
4. 表示数だけを追わない。利益（EPC × CTR − コスト）を報酬にする
5. 「有益な情報」＝価格・割引・配信日・レビュー平均などの**客観データ**を必ず 1 つ入れる（捏造禁止）
