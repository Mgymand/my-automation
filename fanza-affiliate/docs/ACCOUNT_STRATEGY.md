# 新規アカウント戦略（2026-09-28 決定版）

前提: フォロワー 0 から。X への投稿は人間。素材は FANZA 公式のみ。成人向け商品の X 投稿の可否は投稿者本人の判断（`HUMAN_POSTING_NOTICE`）。
根拠は docs/ACCOUNT_RESEARCH.md。

## 1. ポジショニング（70 / 20 / 10）

| 枠 | 割合 | 内容 | 根拠 |
|---|---|---|---|
| メイン | 70% | **買い時（セール速報・激安・値下がり）**: 割引率と期限を先頭に、価格つきで毎日 | 最も再現性が高く、FANZA API から毎日データが取れ、捏造の余地が無い。検索需要が常にある |
| サブ | 20% | **まとめ・掘り出し**: 「安い順 5 本」「レビュー多い順」「レビュー少・評価高」 | 保存・RT されやすく定時化できる。差別化になる |
| 実験 | 10% | **女優訴求 / 新作 / 動画主導 / 問いかけ** | バンディットで枠を回す。反応が出た型をメインへ昇格 |

避けるもの: 1 時間おきの機械連投、同一文型の反復、本文リンク、絵文字過多、AI 美女画像、他者投稿への無差別リプ。

## 3. プロフィール文（3 案 → 採用）

- 案 A（機能型・採用）: FANZA動画の「今買うと得な1本」を毎日メモ。50%OFF以上・100円/10円・新作の割引・レビュー多い掘り出し作品を、価格と期限つきで紹介します｜18歳未満閲覧不可｜投稿にはPRを含みます
- 案 B（人格型）: 毎晩、FANZA の値札を見て回っています。安くなった作品と、その期限をメモ。買い逃したくない人へ｜18 禁｜PR あり
- 案 C（絞り込み型）: 50%OFF 以下と 100 円/10 円だけ。FANZA動画の激安情報を期限つきで毎日｜18 禁｜PR あり

採用理由: A は「誰向け（買い逃したくない人）／何を（得な 1 本）／何が得られる（価格と期限）／頻度（毎日）」が 1 文目で分かる。C は日によってネタが無い。

## 4. ブランド・アイコン・ヘッダー

- 配色: 濃紺 #0F172A（信頼）× 琥珀 #F59E0B（値札・注目）× オフホワイト #F8FAFC
- モチーフ: 値札タグ＋しおり（メモ帳）。文字なし。キャラクターなし（人格は文体で）。清潔・見やすい・怪しく見えない
- アイコン生成プロンプト / ヘッダー生成プロンプト: `affiliate_bot/launch.py` の `ACCOUNT["icon_prompt"]` / `["header_prompt"]`（`launch-posts` が出力）
- プロフィール画像・ヘッダーに成人向け画像は使わない（X 規約）

## 5. 固定投稿

```
このアカウントは、FANZA動画の「今買うと得な1本」を毎日メモするアカウントです。
・50%OFF以上、100円・10円セール、新作の割引を優先
・レビューが多い/評価が高い掘り出し作品も拾います
・価格と期限を必ず書きます（買い逃し防止）
・毎日 夜を中心に 3〜5 件
リンクは各投稿のリプ欄。18歳未満の方は閲覧・購入できません。投稿にはPRを含みます。【PR】
```

## 6. 初期 10 投稿

`python -m affiliate_bot launch-posts` が、DB の実商品（fetch-products 後）の事実だけを使って 10 種の構造で生成する
（1 紹介 / 2 セール速報 / 3 女優 / 4 激安 / 5 新作 / 6 掘り出し / 7 短文 / 8 動画向け / 9 まとめ / 10 フォロー理由）。
該当データが無い型はスキップ表示（捏造しない）。出力: `exports/launch/launch.md`, `post01_*.txt`〜。

## 7. 開始 7 日間の投稿スケジュール（学習期間）

| 日 | 件数 | 型 | 時間帯（枠。分は planner が決める） |
|---|---|---|---|
| Day1 | 3 | 固定投稿 → 紹介 / セール速報 | 夜 21-24 |
| Day2 | 3 | セール速報 / 女優 / 短文 | 昼 12-15 / 夜 18-21 / 夜 21-24 |
| Day3 | 3 | 激安 or セール / 新作 / 動画 | 午前 09-12（セール開始直後）/ 夜 / 夜 |
| Day4 | 4 | まとめ（安い順 5 本）/ セール / 掘り出し / 短文 | 昼 / 夜 / 夜 / 深夜前 |
| Day5 | 4 | セール / 女優 / 動画 / 問いかけ（実験） | 午前 / 昼 / 夜 / 夜 |
| Day6 | 4 | ランキング速報 / セール / 新作 / 人格（挨拶＋今日の 1 本） | 朝 06-09（実験）/ 昼 / 夜 / 夜 |
| Day7 | 5 | フォロー理由強化 / セール / まとめ / 動画 / 掘り出し | 午前 / 昼 / 夕 / 夜 / 夜 |

- 最初から大量投稿しない（3 → 5 件に段階的）。反応を見て `POSTS_PER_DAY` を増減（`planner.suggest_posts_per_day`）。
- 7 日間はテスト期間: セール型 / 女優型 / 新作型 / 短文型 / 動画型を必ず各 2 回以上試す。Pattern の削除はしない（最低サンプル 20 投稿）。
- 各投稿で Views / Likes / Reposts / Replies / Bookmarks（X READ or 手入力）、可能なら Profile visits / Link clicks、フォロワー増減を記録。

## 8. KPI

- 初期（〜CV 20 件）: Views × Engagement × Profile Visit × Link Click × Follow 増を合成（`metrics.blended_reward`）。Views だけで評価しない。
- 以後: EPC / CVR / Revenue per Post を最重要に（Conversion が増えるほど自動で重みが上がる）。

## 9. 30 日運用方針

- 週次（Fable）で 7/30 日を比較し、メイン 70% の内訳（セール速報 : 激安 : 値下がり）と実験枠の昇格・降格を決める。
- 1 日の結果で戦略を変えない。Pattern 削除は 20 投稿以上の実測がある場合のみ。
- 4 週目に「まとめ」の定時化（毎日同時刻）と「人格」の固定フレーズを確定し、固定投稿を更新する。
- 素材は公式サンプル画像・動画のみ。他者の投稿画像・動画・本文は使わない。

## 10. コピーして良いもの / いけないもの

- 良い: 投稿構造、情報の順序、フック形式、文章量、投稿時間、画像枚数、動画尺の傾向、テーマ選定、CTA の位置
- いけない: 本文の丸コピー、画像・動画の転載、アカウント名、プロフィール文、独自キャラクター、独自デザイン、他人のレビュー文章
