# MV「新オフィのフリーレント」

Suno楽曲とアップロード画像から作成したミュージックビデオです。

- **動画**: `MV_ShinOffi_Frieren.mp4`（1280×720 / 約1分48秒）
- **楽曲**: 新オフィのフリーレント（Suno: https://suno.com/s/W6W4GJUb0cBDfAUn ）
- **歌詞**: `lyrics.json`

## 構成
- 背景画像にゆっくりズーム（Ken Burns風）＋フェードイン/アウト
- 歌詞テロップを上→下へ連続スクロール表示
- 曲の後に締めカード「資料作れませんでした。」を表示

※ 歌詞テロップの表示タイミングは曲構成に沿った概算です（Sunoに行単位の時刻情報が無いため）。
