# 中野サロン移転 収支予測（立川2物件・賃貸 vs 売買）

「岩本業務報告書」スプレッドシートの `直営仕入れ中野` および右側の分析シート
（`前提条件` / `購入額目安` / `月次_賃貸` / `月次_購入` / `年次比較_10年` / `評価まとめ`）を
ベースに、実在の2物件へ差し替えて再計算したもの。

物件条件は **40㎡以上・賃料24万円以下**（中野・立川とも同条件）。

## 対象物件

| | 物件A | 物件B |
|---|---|---|
| 名称 | 立川シティハイツ 404号室 | サンパレス立川 302号室 |
| 価格 | 4,499万円（税込） | 1,980万円（税込） |
| 専有 | 56.14㎡ 2LDK | 48.05㎡ 1LDK |
| 築年 | 昭和58年4月（新耐震） | 1981年5月（旧耐震の可能性大） |
| 交通 | 立川駅 徒歩6分 | 立川駅 徒歩7分 |

## 元モデルからの主な修正点

- 購入価格・面積・築年・管理費／修繕積立金・固都税を実物件の数値に差し替え
- 購入諸費用を価格から再計算（登録免許税・不動産取得税・司法書士・印紙）
- **仲介手数料は売買・賃貸ともゼロ**（自社仲介のため。ユーザー確認 2026-08-26）
- 減価償却を築43／45年の中古簡便法（7年）に修正
- 想定エリアが中野→立川に変わるため、売上下振れ（▲20%／▲30%）の感応度を追加
- 「回避できる家賃」を150,000〜240,000円/月で振る感応度を追加
  （月24万円は中野・立川とも上限として確認済み。下振れ側の確認用）
- 10年後の物件価値の感応度を追加（元モデルの中野再開発前提122%は使わない）
- 賃貸側の退去時原状回復費（新店舗・約80万円）を純資産比較に反映
- 定性比較に「造作の自由度」「出口（事業ごと売却）」の観点を追加
- 用途制限（物件Aは事務所利用不可、物件Bは管理規約未確認）を最重要リスクとして明記

## ファイル

- `model.py` — 収支モデル（前提値・月次CF・10年集計・感応度）
- `gen.py` — レポートHTML生成
- `収支予測_*.pdf` — 出力（各2ページ）

## 再生成

```bash
pip install pypdf openpyxl
python3 gen.py
CHROME=/opt/pw-browsers/chromium-1194/chrome-linux/chrome
for k in A B; do
  $CHROME --headless --disable-gpu --no-sandbox --no-pdf-header-footer \
    --print-to-pdf=out/r_$k.pdf file://$PWD/out/r_$k.html
done
```

日本語フォントは IPAGothic を使用。

## 未確定・要検証の前提

- 固定資産税評価額＝価格の50%（推計）。評価証明で要確認
- 物件Bの固都税 年69,432円は物件Aの㎡単価で按分した推計
- 建物比率40%（契約書または固定資産税評価額の按分で確定させる）
- 内装工事費200万円（サロン仕様スケルトン相当）。住居リノベーション済み分は転用時に大半が無駄になる
- 内装工事費200万円は元モデルの値をそのまま使用。坪30万円で引き直すとA約509万円／B約436万円。
  両シナリオ共通の費用のため賃貸／購入の優劣は変わらない
