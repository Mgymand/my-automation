## 全体の流れ（友だち追加から相談まで）

1. 友だち追加すると「あいさつメッセージ」と「開業ナビ一覧カード」が届く。
2. カードの「このナビで相談」を押すと、業種名（例：サロン開業ナビ）が自動で送信される。
3. その業種名に「応答メッセージ」が反応し、業種別のヒアリング項目が届く。
4. お客様が項目を埋めて送信 → 岩本さんがチャットで個別に返信する。
5. 画面下の「リッチメニュー」からも、いつでも業種選択・来店予約・電話・HPに進める。

あいさつメッセージと応答メッセージは、無料メッセージ（月200通）の通数に数えられません。月200通を使うのは「メッセージ配信」だけです。

## 8. メッセージ配信（月200通の使い方）

通数は「友だちの人数 × 配信回数」で数えます。友だち100人なら月2回までが目安です。

| 時期 | 内容 | 形式 |
|---|---|---|
| 毎月上旬 | 開業準備のチェックポイント（電気容量・給排水・排気・用途など、HPの確認ポイントを1つずつ） | テキスト＋画像 |
| 毎月下旬 | 業種別のよくある相談・開業までの流れ | カードタイプ |
| 随時 | 来店相談の空き日程のお知らせ | テキスト |

個別の物件情報を広告として配信する場合は、提携する宅地建物取引業者の名称・免許番号など、法令で必要な表示をそろえてから配信してください。

## 9. 動作確認（設定後に必ず）

1. 自分のLINEで https://lin.ee/SgQ8UQI から友だち追加する（追加済みなら一度ブロック→解除で、あいさつメッセージが届きます）。
2. あいさつメッセージとカード6枚が届くか確認する。
3. 各カードの「このナビで相談」を押して、業種別の項目が返ってくるか確認する。
4. 「その他の業種」→ 7枚のカード → 各ナビの返信を確認する。
5. リッチメニューの6つのボタンをすべて押して確認する。
6. 動かないものは、送信テキストとキーワードが一字一句同じか（「・」や全角・半角）を見直す。

## 10. HP・SNS側でやること

- **HPのLINEボタンがまだLINEにつながっていません。** ヘッダーの「LINE問合せ」、お問い合わせページの「LINE相談へ」「友だち追加する」などが、ページ内の移動のままです。フォーセット様に、リンク先を https://lin.ee/SgQ8UQI にすることと、QRコード画像の差し替えを依頼してください。
- InstagramのプロフィールリンクをこのLINE（https://lin.ee/SgQ8UQI）に変更する。
- 業種ページごとに流入元を分けて計測したい場合は、管理画面の「友だちを増やす」→「友だち追加ガイド」で経路別のURLを作り、各ページのボタンに設定できます。
