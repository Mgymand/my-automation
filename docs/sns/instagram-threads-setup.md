## 2. Threads（スレッズ）について

**結論: 同時に集客できます。むしろ新規アカウントにはInstagramより向いています。**

| 項目 | 内容 |
| --- | --- |
| 開設 | Threadsアプリを入れ、Instagramアカウントでログインするだけ。ユーザー名・プロフィール画像はInstagramと共通 |
| 向いている理由 | 文章中心で画像を作らなくても投稿できる／フォロワー0でも「おすすめ」に載りやすい／投稿にリンクを直接貼れる（Instagramは本文にリンク不可）／「独立・開業」を考える層が多い |
| 投稿の型 | 1投稿500字まで。「開業物件で失敗した実例」「物件を見るときのチェック1つ」「今日の相談から（匿名化）」「質問募集」 |
| 頻度 | 1日1〜2本の短文。Instagramは週2〜3本の画像投稿 |
| 相互連携 | Instagramの投稿を「Threadsにもシェア」で同時投稿できる。Threadsの反応が良い文章を、後でInstagramの画像投稿にする |
| 導線 | プロフィールにLINE／サイトのリンク。投稿末尾は「物件の相談はプロフィールのリンクから」で統一 |

**Threadsで避けること**: 個別物件の情報（住所・賃料・図面）を載せる。無免許での物件広告と見なされるおそれがあるため。「こういう条件の物件が出やすい」までにとどめる。

## 4. Threads 初回投稿10本（そのまま貼れる短文）

1. はじめまして。開業物件の窓口は、独立・開業・移転の物件探しを無料でサポートする相談窓口です。美容事業で全国300店舗の出店に関わってきました。これから「開業物件で失敗しやすい点」を毎日1つ書いていきます。東京・一都三県。
2. サロンの内見で最初に見るのは内装じゃなく、給排水の位置。シャンプー台の数が決まるのはここ。
3. 「居抜きだから安い」は半分だけ正解。前テナントの退去理由と、残った設備の修理費を見てから判断。
4. クリニックの物件は保健所の構造設備基準を契約前に。契約後に「待合の面積が足りない」は本当にある。
5. ジムは床荷重と階下への音。内装費より先に、この2つで物件を落とすかどうか決まる。
6. 飲食店の居抜き、厨房が残っていても「重飲食不可」の物件がある。ラーメン・焼肉は特に確認。
7. 放課後等デイは物件を決める前に指定基準から逆算。用途地域で最初から無理な物件がある。
8. 設立直後の会社でもオフィスは借りられる。保証会社・フリーレント・セットアップ区画、通りやすい条件がある。
9. 自宅サロンをやるなら「サロン可」の賃貸を。一般の住居専用で始めると契約違反になる。
10. 質問募集。開業の物件で「これどうなの？」があれば返信ください。答えられる範囲で答えます。

各投稿の末尾（任意）: 「物件の相談はプロフィールのリンクから」

## 6. 守ること

- 個別の物件情報（住所・賃料・図面・外観が特定できる写真）は投稿しない。
- 「不動産会社」「仲介」と名乗らない。プロフィールに「物件の媒介は提携不動産会社」を残す。
- 「全国300店舗」は根拠を示せる書き方（誰が・どの事業で）に揃えてから使う。
- 既存のInstagramを転用する場合は、ユーザー名・名前・プロフィール文・リンクを上の内容に変え、過去投稿で店舗事業と無関係なものはアーカイブする。

## 7. アイコンの生成プロンプト（ChatGPT 画像生成用）

ポイント: 日本語の文字入れはAIが崩しやすいので、**文字なしのシンボル**か、入れるなら英字「K」1文字まで。小さく表示（110px）されても判別できる単純な形にする。4案ほど出させて選び、気に入った案を「同じデザインで、背景を透過に」「色を紺＋金に」と追加指示で詰める。

**プロンプトA（シンボルのみ・推奨）**

```
ブランド「開業物件の窓口」のアプリアイコン／SNSプロフィール画像を作ってください。
意味：「門出」。新しく事業を始める人・独立する人の、最初の一歩を支える物件相談窓口。
モチーフ：日本の門（鳥居ではない、シンプルな2本柱と横木の門）と、その門をくぐって先へ続く道、または昇る朝日。
スタイル：フラットデザイン、幾何学的、太めの線、ミニマル。文字は入れない。
色：背景は濃いネイビー（#1E3A8A）、シンボルは白、アクセントに金（#E5C06B）を一か所だけ。
形：正方形 1080×1080px、中央に大きくシンボルを配置、余白は上下左右12%。
条件：110pxまで縮小しても形が判別できること。グラデーション・写真風・影・複雑な装飾は使わない。
4パターン提案してください。
```

**プロンプトB（英字K入り）**

```
ブランド「開業物件の窓口」のSNSプロフィール用ロゴマークを作ってください。
モチーフ：大文字の「K」を、日本の門（2本の柱と横木）の形と一体化させる。Kの縦線が門の柱、斜め線が開いた扉や進む道に見えるように。
スタイル：フラット、幾何学的、ミニマル。文字はこの「K」以外入れない。
色：ネイビー（#1E3A8A）の背景に白のK、横木だけ金（#E5C06B）。
形：正方形 1080×1080px、中央配置、余白12%。110pxに縮小しても判別できる太さ。
4パターン提案してください。
```

**プロンプトC（店舗向け・親しみ寄り）**

```
「開業物件の窓口」という、お店を開業する人のための物件相談窓口のアイコンを作ってください。
モチーフ：小さな店舗の扉が少し開いていて、中から光が差している。または「OPEN」の札がかかった扉。
スタイル：フラットで丸みのあるシンプルな図形、2〜3色、文字なし。
色：ネイビー（#1E3A8A）、白、金（#E5C06B）の3色のみ。
形：正方形 1080×1080px、中央配置、余白12%。小さく表示されても形が分かること。
4パターン提案してください。
```

**選んだ後に追加で頼むこと**

1. 「この案で、背景が透過のPNGも出してください」（サイトのヘッダー用）
2. 「同じデザインで、横長のロゴ（シンボル＋『開業物件の窓口』の文字、1600×400px）も作ってください」（サイト・名刺用。文字が崩れたら文字は自分で入れる）
3. 「色だけ変えて、サロン用（ピンク系）・クリニック用（青緑系）・飲食用（オレンジ系）の3色展開も」（業種別アイコンの差し色に使う）

**確認ポイント**: スマホでInstagramを開いたときの丸い小さな表示で、何の形か分かるか。分からなければ線を太く、要素を減らす。
