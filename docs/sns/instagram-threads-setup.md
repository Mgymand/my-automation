## 2. Threads（スレッズ）について

**結論: 同時に集客できます。むしろ新規アカウントにはInstagramより向いています。**

| 項目 | 内容 |
| --- | --- |
| 開設 | Threadsアプリを入れ、Instagramアカウントでログインするだけ。ユーザー名・プロフィール画像はInstagramと共通 |
| 向いている理由 | 文章中心で画像を作らなくても投稿できる／フォロワー0でも「おすすめ」に載りやすい／投稿にリンクを直接貼れる（Instagramは本文にリンク不可）／「独立・開業」を考える層が多い |
| 投稿の型 | 1投稿500字まで。「開業物件で失敗した実例」「物件を見るときのチェック1つ」「今日の相談から（匿名化）」「質問募集」 |
| 頻度 | 1日1〜2本の短文。Instagramは週2〜3本の画像投稿 |
| 相互連携 | Instagramの投稿を「Threadsにもシェア」で同時投稿できる。Threadsの反応が良い文章を、後でInstagramの画像投稿にする |
| 導線 | プロフィールにLINE／サイトのリンク。投稿末尾は「物件の相談はプロフィールのリンクから」で統一 |

**Threadsで避けること**: 個別物件の情報（住所・賃料・図面）を載せる。無免許での物件広告と見なされるおそれがあるため。「こういう条件の物件が出やすい」までにとどめる。

## 4. Threads 初回投稿10本（そのまま貼れる短文）

1. はじめまして。開業物件の窓口は、独立・開業・移転の物件探しを無料でサポートする相談窓口です。美容事業で全国300店舗の出店に関わってきました。これから「開業物件で失敗しやすい点」を毎日1つ書いていきます。全国対応。
2. サロンの内見で最初に見るのは内装じゃなく、給排水の位置。シャンプー台の数が決まるのはここ。
3. 「居抜きだから安い」は半分だけ正解。前テナントの退去理由と、残った設備の修理費を見てから判断。
4. クリニックの物件は保健所の構造設備基準を契約前に。契約後に「待合の面積が足りない」は本当にある。
5. ジムは床荷重と階下への音。内装費より先に、この2つで物件を落とすかどうか決まる。
6. 飲食店の居抜き、厨房が残っていても「重飲食不可」の物件がある。ラーメン・焼肉は特に確認。
7. 放課後等デイは物件を決める前に指定基準から逆算。用途地域で最初から無理な物件がある。
8. 設立直後の会社でもオフィスは借りられる。保証会社・フリーレント・セットアップ区画、通りやすい条件がある。
9. 自宅サロンをやるなら「サロン可」の賃貸を。一般の住居専用で始めると契約違反になる。
10. 質問募集。開業の物件で「これどうなの？」があれば返信ください。答えられる範囲で答えます。

各投稿の末尾（任意）: 「物件の相談はプロフィールのリンクから」

## 6. 守ること

- 個別の物件情報（住所・賃料・図面・外観が特定できる写真）は投稿しない。
- 「不動産会社」「仲介」と名乗らない。プロフィールに「物件の媒介は提携不動産会社」を残す。
- 「全国300店舗」は根拠を示せる書き方（誰が・どの事業で）に揃えてから使う。
- 既存のInstagramを転用する場合は、ユーザー名・名前・プロフィール文・リンクを上の内容に変え、過去投稿で店舗事業と無関係なものはアーカイブする。

## 7. ロゴの生成プロンプト（ChatGPT 画像生成用・大手ロゴ調査を反映）

使い方: `docs/sns/logo/logo-directions.png`（3方向の構成案）を**参考画像として添付**し、下のプロンプトを貼る。4案出させて選び、追加指示で詰める。

**メインプロンプト（案3：紺の文字＋朱の差し色）**

```
添付画像の「案3」の構成をもとに、プロのデザイナーが作ったような高品質なロゴを作ってください。

ブランド名：開業物件の窓口（副名：KADODE）
事業：独立・開業・移転する人のための店舗・オフィス物件の無料相談窓口。
目指す印象：「ほけんの窓口」「at home」のように、文字が主役で、太く、少し丸みのある親しみやすい書体。信頼感と気軽さの両立。

構成（横長ロゴ）：
- 左に小さなシンボル：2本の柱と横木でできたシンプルな門。門の中の下部に朝日の半円。鳥居には見えないよう、角の丸い幾何学的な形で。
- 右に大きく「開業物件の窓口」。極太の丸ゴシック体。文字は濃紺（#1E3A8A）、「の」の1文字だけ朱色（#F0772B）。
- その下に小さく「KADODE」（細めのサンセリフ、文字間を広く、朱色）。
- 文字は必ず正確に「開業物件の窓口」「KADODE」と描いてください。字形を崩さないこと。

スタイル：フラット、ベクター風、2色（濃紺・朱）＋白。影・グラデーション・質感・飾り罫は使わない。余白を広く。
出力：白背景の横長（1800×600px）。同じデザインで4パターン（書体の丸みや門の太さを変えたもの）を提案してください。
```

**追加の指示（選んだ後）**

1. 「この案で、正方形のSNSアイコン版（1080×1080）を作ってください。上に門のシンボル、下に『開業物件の窓口』、その下に小さく『KADODE』。背景は濃紺、文字は白、朝日と『の』と『KADODE』は朱色」
2. 「同じデザインで、背景が透過のPNGも出してください」
3. 「文字の形が崩れています。『開業物件の窓口』を正確な字形で描き直してください。他は変えないでください」（崩れた場合）
4. 「ゴールド（#E5C06B）を差し色にした版も1枚」（紺×金の雰囲気も見たい場合）

**別案のプロンプト差分**

- 案2（朱色の文字・ほけんの窓口型）: 上のプロンプトの色指定を「文字は朱色（#E24A2B）、門のシンボルも朱色、朝日は黄色（#F5B335）、KADODE は朱色」に変える。
- 案1（紺・金の現行色）: 「文字は濃紺、門は濃紺、朝日と KADODE はゴールド（#B8912F）。KADODE は文字の上に小さく」に変える。

**注意**: 画像生成は日本語の字形を崩しやすい。崩れたら、生成画像のシンボル部分だけを使い、文字は `docs/sns/logo/logo-directions-source.html` から書き出したものを重ねる方が確実。
