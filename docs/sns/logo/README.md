# 開業物件の窓口 ロゴ

## 採用ロゴ（`final/`）

ChatGPT画像生成で作成した案3（紺×朱・丸ゴシック・門と朝日）を、ブランド3色（紺 #1E3A8A／朱 #F0772B／白）に色を揃えて整えたもの。

| ファイル | 用途 |
| --- | --- |
| final/logo-wide-white.png | サイトヘッダー・名刺・資料（白地） |
| final/logo-wide-navy.png | 紺地の帯・フッター |
| final/logo-wide-transparent.png | 背景透過（どこにでも置ける） |
| final/icon-square-navy.png | SNSプロフィール画像（Instagram・Threads・LINE） |
| final/icon-square-white.png | 白地のアイコン・ファビコン元 |
| final/mark-transparent.png | 門のシンボルのみ（ファビコン・アプリアイコン） |
| final/wordmark-transparent.png | 文字部分のみ |

フォーセット様にはこの `final/` 一式を渡す。ベクター化（SVG/AI）が必要なら、この PNG をもとにトレースしてもらう。

## 検討経緯

- `benchmark-headers.png`：大手サイトのヘッダー比較（ほけんの窓口・at home・オフィスナビ・canaeru など）
- `logo-directions.png` / `logo-directions-source.html`：大手の共通点を反映した3方向
- `madoguchi-*`：初期案（門・扉・バッジ、正方形・横長）。`madoguchi-logo-source.html` が編集用ソース
