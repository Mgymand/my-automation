# 老人シェアハウス（住宅型有料老人ホーム）物件ヒアリングシート

既存の「マンスリー物件掲載ヒアリングシート」を、老人シェアハウス（住宅型有料老人ホーム）用に
作り替えたもの。A4 タテ **1枚** で完結する。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `elderly-sharehouse-hearing-sheet.html` | 1枚版の原本（これを編集する） |
| `elderly-sharehouse-hearing-sheet.pdf` | 1枚版の印刷用 PDF（A4 1ページ） |
| `elderly-sharehouse-hearing-sheet-2p.html` | 2枚版の原本 |
| `elderly-sharehouse-hearing-sheet-2p.pdf` | 2枚版の印刷用 PDF（A4 2ページ） |
| `elderly-sharehouse-hearing-sheet-sample.html` | 1枚版の記入例の原本 |
| `elderly-sharehouse-hearing-sheet-sample.pdf` | 1枚版の記入例（A4 1ページ） |
| `build.sh` | HTML → PDF 変換スクリプト（すべてまとめて出力） |

## 更新のしかた

1枚版と2枚版は別ファイルで、内容はほぼ同じ。**1枚版が原本**で、項目を変えたときは
2枚版にも同じ変更を反映すること。

HTML を編集したあと、次を実行して PDF を作り直す（両方まとめて出力される）。

```bash
./docs/hearing-sheet/build.sh
```

Chromium（headless）と日本語フォント（IPAGothic 等）が必要。
Chromium のパスは `CHROME_BIN` 環境変数で指定できる。

## 記載事項

- 上部に **エリア** の記入欄（枠付き・大きめ）
- 基本情報：物件名／所在地／建物名／最寄駅／築年数／構造／階数／扶助額／**価格（売買のみ）**
- 部屋情報：間取り／**延床面積（1F・2Fの内訳）**／想定部屋数／土地面積（別途私道・持分）／**接道（幅員・間口・道路種別）**
- 設備（一戸建て用・マイソクの記載事項を参考）
- **告知事項・瑕疵の確認**（心理的／物理的／土地・環境／法令上／権利・近隣）
- **取得・確認資料チェックリスト**（地図／法務局／インフラ／接道／売主）
- アピールポイント・周辺環境／注意事項／緊急連絡先（元付／売主・担当・TEL／FAX・MAIL）
- 法規制確認（建築・消防のリーガル確認8点、役所・消防本部への確認、内装工期）

## マンスリー版からの変更点

- 基本情報に **価格**（売買／賃貸・月）を追加
- 基本情報に **扶助額**（円／人・月）を追加
- 部屋情報の **定員 → 想定部屋数** に変更（あわせて延べ面積・2階居室面積計・土地面積の記入欄を追加）
- **ペット** の欄を削除
- **喫煙** の欄を削除
- **設備** をマイソクの記載事項を参考に一戸建て用へ変更
  （敷地・外構／建物・防犯／キッチン／浴室・洗面／トイレ／インフラ／バリアフリー／消防設備）
- **料金** のブロックを削除
- **鍵の種類と明け渡し方法** のブロックを削除
- **利用条件**（法人契約・外国人・保証人）のブロックを削除
- 「新規／既存転用」「建物（マンション・アパート・戸建）」の欄を削除
- 価格は売買前提のため「□売買 □賃貸/月」の区分を削除
- 面積を「延床（1F・2Fの内訳）」に変更
- 上部に **エリア** の記入欄を追加
- **取得・確認資料チェックリスト** を追加（ゼンリン住宅地図／登記事項証明書・公図・地積測量図・建物図面／水道・下水道・ガス／接道と道路台帳・指定道路）
- **法規制確認**（建築・消防のリーガル確認8点、役所〈建築指導課〉確認、消防本部確認、内装工期）を追加
- 緊急連絡先の「仲介会社」を **元付／売主** に変更
- 部屋情報に **接道**（幅員・間口・道路種別）の行を追加。土地面積は「別途 私道・持分」の欄に整理
- **告知事項・瑕疵の確認** のブロックを追加

## 編集時の注意

枠線は **1.5pt** にしてある。これより細くすると、Chromium が枠線を小数座標の塗り
矩形として出力する都合で、PDF ビューアや印刷時にアンチエイリアスに溶けて線が消え
たり薄く見えたりする（特に縦線）。細くしたくなった場合は、生成した PDF を 72／96／
150 dpi でラスタライズして、左右の縦線が黒く出ることを確認すること。

## 2枚版について

現地ヒアリングや役所回りでその場に書き込む用に、記入スペースを広げた A4 2枚版。
1枚版との違いは次のとおりで、項目そのものは同じ。

- 文字と行間を大きくし、表の各行を高くした
- 1ページ目：エリア／基本情報・連絡先／部屋情報／設備 ＋ **内装図面・間取図の貼付欄**
  （ページ下部の約2/5。マイソクの間取図・配置図をそのまま貼れる大きさ）
- 2ページ目：告知事項／取得・確認資料チェックリスト／アピールポイント・注意事項／
  法規制確認 ＋ **特記事項・総合所見欄**（進める・保留・見送りの判定つき）
- 2枚版の基本情報は「物件名｜所在地」「価格｜最寄駅」「築年数｜構造」「階数｜扶助額」
  「元付／売主｜担当」「TEL／FAX｜MAIL」の2列6行。建物名は戸建では使わないため省いてある
  （1枚版には残してある）
- 連絡先は独立ブロックにせず基本情報の表に統合し、1ページ目で完結するようにした
- 2ページ目にも見出しと物件名欄を入れ、ページが離れても対応が分かるようにした
- 図面貼付欄は flex で残り高さいっぱいに広がるので、上の項目を足し引きしても
  ページからはみ出さない

## 記入例について

`elderly-sharehouse-hearing-sheet-sample` は、実際の物件（春日部市東中野の中古住宅・
930万円・現況6DK → **9室に分割**する想定）を1枚版に落とし込んだ記入例。
マイソク・登記事項証明書（土地／建物）・公図・地積測量図・建物図面・内装資料から
確定できる項目には ☑ と値が入り、確定できない項目は「要確認」と書いてある。
新しい物件を見るときの記入の目安に使う。

この記入例で判明している主な論点：

- 9室に分割すると全室が13㎡未満になるが、有料老人ホーム設置運営標準指導指針 6⑴の
  「既存建築物等の活用の場合等の特例」（既存転用または定員9人以下）で適用除外を狙える。
  全室個室・重要事項説明書への記載・代替措置が条件で、最終判断は都道府県（埼玉県）。
- 延べ面積118.92㎡・階数2なので、用途変更の建築確認は不要（法87条・200㎡以下）、
  耐火／準耐火建築物とすることも不要（同指針 6⑶）。
- 土地の登記地積は148㎡でマイソクの164㎡と16㎡食い違う。
- 分割後、採光1/7を満たせない居室が2室出る見込み。

テンプレート側の項目を変えたときは、記入例も追随させるか、古くなった旨を書き添えること。
