# 老人シェアハウス（住宅型有料老人ホーム）物件ヒアリングシート

既存の「マンスリー物件掲載ヒアリングシート」を、老人シェアハウス（住宅型有料老人ホーム）用に
作り替えたもの。A4 タテ **1枚** で完結する。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `elderly-sharehouse-hearing-sheet.html` | 原本（これを編集する） |
| `elderly-sharehouse-hearing-sheet.pdf` | 印刷用 PDF（A4 1ページ） |
| `build.sh` | HTML → PDF 変換スクリプト |

## 更新のしかた

HTML を編集したあと、次を実行して PDF を作り直す。

```bash
./docs/hearing-sheet/build.sh
```

Chromium（headless）と日本語フォント（IPAGothic 等）が必要。
Chromium のパスは `CHROME_BIN` 環境変数で指定できる。

## 記載事項

- 上部に **エリア**（例：埼玉県春日部市）の記入欄
- 基本情報：物件名／所在地／建物名／最寄駅／築年数／構造／階数／扶助額／**価格（売買のみ）**
- 部屋情報：間取り／**延床面積（1F・2Fの内訳）**／想定部屋数／土地面積（私道）
- 設備（一戸建て用・マイソクの記載事項を参考）
- **取得・確認資料チェックリスト**（地図／法務局／インフラ／接道）
- アピールポイント・周辺環境／注意事項／緊急連絡先
- 週次アクション（建築・消防のリーガル確認8点、役所・消防本部への確認、内装工期）

## マンスリー版からの変更点

- 基本情報に **価格**（売買／賃貸・月）を追加
- 基本情報に **扶助額**（円／人・月）を追加
- 部屋情報の **定員 → 想定部屋数** に変更（あわせて延べ面積・2階居室面積計・土地面積の記入欄を追加）
- **ペット** の欄を削除
- **喫煙** の欄を削除
- **設備** をマイソクの記載事項を参考に一戸建て用へ変更
  （敷地・外構／建物・防犯／キッチン／浴室・洗面／トイレ／居室・内装／インフラ／バリアフリー／消防設備）
- **料金** のブロックを削除
- **鍵の種類と明け渡し方法** のブロックを削除
- **利用条件**（法人契約・外国人・保証人）のブロックを削除
- 「新規／既存転用」「建物（マンション・アパート・戸建）」の欄を削除
- 価格は売買前提のため「□売買 □賃貸/月」の区分を削除
- 面積を「延床（1F・2Fの内訳）」に変更
- 上部に **エリア** の記入欄を追加
- **取得・確認資料チェックリスト** を追加（ゼンリン住宅地図／登記事項証明書・公図・地積測量図・建物図面／水道・下水道・ガス／接道と道路台帳・指定道路）
- **週次アクション**（建築・消防のリーガル確認8点、役所〈建築指導課〉確認、消防本部確認、内装工期）を追加
