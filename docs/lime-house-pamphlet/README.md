# LIME HOUSE パンフレット 構成・配置指示（A4縦 4ページ）

住宅型有料老人ホーム「LIME HOUSE」（埼玉県加須市向古河670-4／2026年10月1日開設・定員9名）の
パンフレット4ページ分の割り付け指示書。

- `layout-spec.html` — ページごとのワイヤーフレーム（A4比率）＋ブロック指示＋そのまま使える原稿

## ページ構成

| ページ | 役割 | 主なブロック |
|---|---|---|
| P1 | 表紙 | キャッチコピー／外観写真／3つの約束／基本スペック帯 |
| P2 | 想い・暮らし | 原点ストーリー／特徴1〜3＋連携図／食事・居室・共用の写真 |
| P3 | 受け入れ体制 | 入居条件／医療的ケア・疾患別 受け入れ一覧（主役）／職員・夜間体制／協力医療機関 |
| P4 | 料金・概要 | 月額内訳表（合計6〜9万円）／施設概要／設備／アクセス／入居までの流れ／問い合わせ |

## 打ち出す差別化（面積配分の優先順）

1. 介護度が上がっても月額が変わらない（上乗せ介護費・生活支援サービス費・その他すべて0円）
2. 月々9万円以内・住宅扶助の範囲で収まる
3. 身元保証人・身元引受人が不明でも相談可／全国から受け入れ
4. 医療の受け入れ範囲を条件つきで具体的に開示（ヤールⅢまで、褥瘡ステージⅡまで 等）
5. グループ内の訪問介護＋近隣の訪問看護＋埼玉県済生会加須病院の連携
6. 3食手作り／9名の小規模／新古河駅 徒歩1分

## 制作前に確定が必要な項目

電話・FAX・メール・HP／運営会社の正式名称と代表者名／職員数・勤務形態／調理場所／1日の流れ／写真の掲載許諾。
表現面では「駅から徒歩10秒」→「徒歩1分」への統一、看取り実績なしの書き方、認知症による契約解除条件の扱いを
`layout-spec.html` の「05 制作前に確定が必要な項目」に記載。
