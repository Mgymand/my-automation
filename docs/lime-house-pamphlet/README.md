## 1. 制作の目的・概要

埼玉県加須市に新規開設する住宅型有料老人ホーム「Lime HOUSE（ライムハウス）」の入居者募集のためのパンフレットを制作します。**生活保護を受給されている方（受給を希望される方を含む）が安心して入居を検討できることが最重要の訴求ポイント**です。入居検討者ご本人・ご家族のほか、ケアマネジャー・地域包括支援センター・行政の窓口（生活保護担当ケースワーカー）への配布を想定しています。

| 項目 | 内容 |
|---|---|
| 成果物 | 見開き両面3ページのパンフレット（A4仕上がり・巻三つ折り／展開A4横3面×両面＝計6面を想定。同等の見開き構成であればA3二つ折り等の代替提案も歓迎） |
| 納品形態 | 印刷入稿用データ（PDF/X または ai）＋Web掲載用PDF |
| 想定読者 | ①入居検討者本人（要介護認定を受けた方。生活保護受給者・受給希望者を含む） ②そのご家族 ③ケアマネジャー・相談員・行政窓口（生活保護担当） |
| 部数・印刷 | 印刷は別途手配予定（データ納品まで）。用紙はマットコート系を想定 |
| スケジュール | ラフ案→初稿→修正（2回程度を想定）→校了。具体的な日程は別途ご相談 |

## 3. デザインの方向性（トーン＆マナー）

- **キーカラー**：ブランド名「Lime」にちなんだライムグリーン（黄緑）×白を基調に、清潔感・健康・みずみずしさを表現。下の全体見本のような「緑基調で余白を活かしたカタログ的な構成」が全体イメージに最も近い。
- **費用メリットの訴求**：「家賃 月3万円」「介護費の自己負担 実質0円※」「扶助の範囲を超えた分だけのご負担」という数字のメリットを、料金面だけでなく表紙まわりでも目に入るよう、バッジ・帯などで大きく扱う（※印で条件注記を必ず併記）。
- **書体**：高齢の読者とご家族が読みやすい、丸みのあるゴシック系。本文は大きめの級数・十分な行間。
- **写真**：入居者・スタッフの自然な笑顔、明るい自然光の写真を中心に。支給が間に合わない箇所はイメージ素材で仮当てし、差し替え可能な作りに。
- **印象**：「介護施設らしい重さ」よりも「美容と健康の会社がつくる、明るく清潔な住まい」という新しさ・親しみやすさを優先。ただし費用の話題が中心になるため、安っぽくならず、ご家族・行政窓口が見ても信頼感のあるトーンに。
