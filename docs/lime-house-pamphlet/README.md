## 1. 制作の目的・概要

埼玉県加須市に新規開設する住宅型有料老人ホーム「Lime HOUSE（ライムハウス）」の入居者募集のためのパンフレットを制作します。入居検討者ご本人・ご家族のほか、ケアマネジャー・地域包括支援センター・行政の窓口（生活保護担当含む）への配布を想定しています。

| 項目 | 内容 |
|---|---|
| 成果物 | 見開き両面3ページのパンフレット（A4仕上がり・巻三つ折り／展開A4横3面×両面＝計6面を想定。同等の見開き構成であればA3二つ折り等の代替提案も歓迎） |
| 納品形態 | 印刷入稿用データ（PDF/X または ai）＋Web掲載用PDF |
| 想定読者 | ①入居検討者本人（原則65歳以上・要介護認定を受けた方） ②そのご家族（40〜60代） ③ケアマネジャー・相談員・行政窓口 |
| 部数・印刷 | 印刷は別途手配予定（データ納品まで）。用紙はマットコート系を想定 |
| スケジュール | ラフ案→初稿→修正（2回程度を想定）→校了。具体的な日程は別途ご相談 |

## 3. デザインの方向性（トーン＆マナー）

- **キーカラー**：ブランド名「Lime」にちなんだライムグリーン（黄緑）×白を基調に、清潔感・健康・みずみずしさを表現。下の全体見本のような「緑基調で余白を活かしたカタログ的な構成」が全体イメージに最も近い。
- **書体**：高齢の読者とご家族が読みやすい、丸みのあるゴシック系。本文は大きめの級数・十分な行間。
- **写真**：入居者・スタッフの自然な笑顔、明るい自然光の写真を中心に。支給が間に合わない箇所はイメージ素材で仮当てし、差し替え可能な作りに。
- **印象**：「介護施設らしい重さ」よりも「美容と健康の会社がつくる、明るく清潔な住まい」という新しさ・親しみやすさを優先。ただし過度にポップにせず、ご家族・行政窓口が見ても信頼感のあるトーンに。

1. **安心の生活サポート** — スタッフが日々の暮らしを見守り、食事・掃除・洗濯などの生活支援を提供。訪問介護・訪問看護など外部の介護サービスと連携し、お一人おひとりのケアプランに沿った暮らしを支えます。
2. **美容と健康のケア** — 美容サロン運営で培った知識を活かし、清潔で心地よい環境づくりと、身だしなみ・スキンケアなど「きれいでいられる」サポートを大切にします。きれいになることは、外出や交流の意欲、心の健康につながります。
3. **無理のない費用設定** — 長く安心して暮らしていただけるよう、費用を抑えた料金設定としています。生活保護を受給されている方・受給をご希望の方もご相談いただけます。
