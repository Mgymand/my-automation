## 0. 先に決めておくこと（サイトの前提）

### 0-1. 法令上の立ち位置（ここを外すとサイト自体が作り直しになります）

| 事項 | 内容 |
| --- | --- |
| 宅建業免許 | ギマンドマンマンは免許を持たない。物件の媒介（条件交渉・重要事項説明・契約）は**提携の宅建業者**が行い、当方は「出店相談の受付と提携会社へのご紹介」に専念する。 |
| サイト上の名乗り | 「不動産会社」「不動産仲介」「仲介手数料」という表現は使わない。「店舗物件探しの相談窓口」「出店サポート」「物件のご紹介は提携不動産会社（免許番号○○）が担当」と明記する。 |
| 物件情報の掲載 | 個別物件（住所・賃料・図面）はサイトに載せない。無免許での物件広告・媒介とみなされる恐れがあるため。載せるのは「探し方・費用相場・エリア解説・事例（匿名化）」までにする。 |
| 紹介料20% | 岩本さんは提携会社の社員でもあるため、「個人事業（ギマンドマンマン）として集客した顧客を会社に紹介し、成約時に20%を受け取る」ことを**紹介（業務提携）契約書**として会社と文書化しておく（副業の承認・報酬の根拠・当方は個人事業として媒介行為をしないこと）。確定申告上は個人事業の売上として処理。 |
| 内装 | 施工は提携施工会社。当方は紹介のみなので建設業許可は不要。サイトでは「提携施工会社が施工（建設業許可 ○○）」と記載する。 |
| 渋谷の住所 | 提携会社の事務所。掲載の了承は**取得済み**。「渋谷相談窓口（提携会社○○オフィス内・要予約）」と書き、本部（海老名）を正式所在地にする。サイトの運営者はギマンドマンマンであり、提携会社が運営しているように見える表記は避ける。 |

参考: 紹介料の受け取り自体は違法ではないが、報酬を得て媒介に実質関与すると無免許営業になり得る、という整理が一般的です。
出典: [不動産の紹介料をもらう副業は宅建業法違反か](https://atsoho.com/blog/real-estate-referral-fee-legality) ／ [宅建業法 第12条の解説](https://takken-success.info/takken-gyoho/article-12)
最終判断は提携会社の宅建士か、都道府県の宅建業担当課へ一度確認することをおすすめします。

### 0-2. ブランド構成（決定）

- **親ブランド：開業物件の窓口**（運営：ギマンドマンマン）。新しく事業を始める人・開業する人・独立を目指す人・移転や業態転換などの転換点にいる人の「門出」に、全国300店舗の出店に携わった出店ジェネラリストが伴走する、という大元の打ち出し。業界の主流（飲食店ドットコム・居抜き店舗.com 等）に合わせ、親も業種別も「客が検索する言葉」をそのまま名前にする。「窓口」で無料相談・中立の立ち位置を伝える。
- **業種別ブランド：「○○開業ナビ」**で統一し、**11ブランドすべてを初回制作に含める**（公開後の追加は前提にしない）：サロン／クリニック／ジム・ピラティス／治療院／福祉・介護／学習塾／ペットショップ／飲食店／買取・リユース／宿泊・インバウンド／オフィス開設・移転 ＋ 住まい探し。一覧にない業種は「その他」で受ける。
- **対象は賃貸のみ（売買は扱わない）。**
- フォーセット様のプランは全7ページのため、サロン／クリニック／飲食店／オフィスを単独ページ、残り7ブランド＋住まい探しを1ページに束ねて収める。文言は検索語を多く含む形で `docs/hp-forset-brands.md` 1-2 にまとめた。詳細（各ブランドの対象・根拠・物件要件・検索ワード・許認可・7ページ構成）は **`docs/hp-forset-brands.md`** を参照。
- 1ドメイン＋ブランド別ディレクトリ構成（SEO評価を集約するため）。独自ドメインの分割は行わない。
- 「300店舗」の表現は事実確認のうえ、根拠を示せる書き方にする（例：「代表は○○の店舗開発として全国300店舗の出店に従事」）。

### 0-4. 居住用（住まい探し）の取り込み方

居住用の客も提携会社へ紹介したい、とのことなので、サロン開業ナビの中に「住まい探し」の入口を自然に置きます。
ブランドを分けずに受け皿を作ります（居住用専門サイトは作らず、開業物件の窓口内の1ページで受ける）。

| 入口 | 想定する客 | 検索ワード例 |
| --- | --- | --- |
| **マンションサロン・自宅サロン向けの住まい探し** | 店舗を借りずに自宅やマンションの一室で開業したい人（店舗客と同じ検索行動で来る） | マンションサロン 物件／自宅サロン 賃貸 可／サロン可 マンション 東京／店舗兼住宅 賃貸 |
| **開業に合わせた引越し・スタッフの住まい** | 出店エリアの近くに住み替えるオーナー、採用したスタッフの社宅・寮 | 渋谷 賃貸 単身／職場近く 賃貸 相談／社宅 代行 小規模 |
| **住まいの修理マッチングからの送客** | 既存サイトに来ている一般の住宅客（修理相談のついでに住み替え相談） | 既存サイトに「お部屋探しのご相談」バナーを追加するだけで済む |
| **一般のお部屋探し相談** | 上記以外の居住用。フォームの「ご相談内容」で「お住まい探し」を選べるようにする | 渋谷区 賃貸／海老名 賃貸／厚木 賃貸 |

提携会社への紹介は「個人事業のつてで集客した方のご紹介」として、店舗客と同じ紹介契約・同じ料率で扱えるよう先に確認しておく（居住用は賃料が低く紹介料も小さいため、料率や最低額の取り決めを）。
サイト上の表記は店舗と同じで、「物件のご紹介・媒介は提携不動産会社が行います」を居住用ページにも入れる。個別物件は載せない。

**具体的な事業内容**

0. **親ブランド「開業物件の窓口」（門出）**
   新しく事業を始める方、開業する方、独立を目指す方、移転・業態転換・2号店などの転換点にいる方の「門出」に伴走する相談窓口。美容事業で全国300店舗の多店舗展開に携わった出店ジェネラリスト（代表 岩本）が、業種ごとの専門窓口（○○開業ナビ）を運営。業種特有の物件要件（用途地域・電気容量・排気・床荷重・許認可）を踏まえて、提携不動産会社・提携施工会社へつなぐ。対象業種はサロン／クリニック／ジム・ピラティス／無人店舗／福祉・介護／飲食／治療院／教育／ペット／買取・リユース／体験・レジャー／宿泊・インバウンド／オフィス移転の13業種で、すべて公開時から掲載する。扱うのは賃貸のみで売買は行わない（詳細は `docs/hp-forset-brands.md`）。
1. **店舗（サロン）向け物件探しの相談窓口**
   美容室・エステ・ネイル・まつエク・整体院・リラクゼーションなどのサロン開業者から、希望エリア・坪数・予算・開業時期をヒアリングし、店舗テナントの賃貸仲介を専門とする提携不動産会社（宅地建物取引業者）へおつなぎします。物件のご案内・条件交渉・重要事項説明・契約は提携不動産会社が行い、当方は相談受付と紹介、開業までの伴走を担当します。対応エリアは東京を中心に全国対応（一都三県は内見同行・来訪相談も可）。相談料は無料。

**今回ホームページをお申込みになった理由**

- 店舗（サロン）テナントに特化した相談窓口として、検索からの新規問い合わせを安定して得たい。
- 提携不動産会社・提携施工会社と組んだ「物件＋内装＋開業後の修理・集客」のワンストップを一つのブランドとして打ち出したい。
- 既存のホームページは軽微な修正しかできず、新ブランドの立ち上げ・エリアページや記事の追加・SEOに対応できないため、上位表示を前提に設計された新しいサイトが必要。
