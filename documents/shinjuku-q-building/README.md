# 新宿Qビル3階 定期建物賃貸借契約 解約通知書

貸主（株式会社邱永漢事務所）からの 2026年9月10日付「定期建物賃貸借契約に関するご通知」に対し、
借主から提出する解約通知書。加盟店本部である株式会社Lime が解約日の翌日から本物件を契約すること
を条件に、違約金の免除または減額を相談する内容を含む。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `解約通知書_新宿Qビル3階.docx` | 提出用（印刷 → 署名・実印押印 → 返送） |
| `解約通知書_新宿Qビル3階.txt` | 同内容のテキスト版（文面の下書き・差し替え用） |
| `generate_kaiyaku_tsuchisho.js` | docx を生成するスクリプト（`npm i docx` 後に `node generate_kaiyaku_tsuchisho.js 出力先.docx`） |

## 提出前に記入・確認が必要な箇所

- 日付（作成日）、賃借人の所在地・法人名・代表者名（個人契約の場合は住所・氏名）、押印
- 解約申し入れ日、解約方法（予約解約／即時解約のチェック）、契約終了日
- 退室立会希望日時、精算金返還先口座、明渡し後の連絡先
- 引用した契約条項（第18条・第18条第2項）、契約日（2026年6月29日付）、契約期間満了日（2029年6月30日）が
  実際の契約書と一致しているか
