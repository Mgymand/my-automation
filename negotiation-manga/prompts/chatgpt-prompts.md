# ChatGPT（画像生成）向けプロンプト集 — 価格交渉マンガ 全11ページ

使い方
1. ChatGPT に **`characters/character_sheet.png`（3人のキャラ設定シート1枚）** を添付し、まず「■ ステップ0（画風統一）」を送って、3人を同じ画風で描き直した設定画を作らせる。
   できた設定画を保存し、以降はそれを添付して「■ 共通プロンプト」を送る。
   （元の立ち絵3枚 `characters/01〜03_*.png` も一緒に添付すると、さらに一貫性が上がります）
2. 続けて「■ ページ1」…「■ ページ11」を **1メッセージに1ページずつ** 送る（同じスレッド内で）。
3. セリフが崩れたら、そのページだけ「吹き出しの文字を修正して再生成：〜」と送る。
   どうしても直らない場合は「吹き出しは空白のままにして」と付け足して生成し、文字は後から別途入れる（このリポジトリの `index.html` のセリフ一式が流用できます）。
4. キャラの顔や服が変わったら「添付のキャラ設定シートと同じ外見に戻して」とシートを再添付する。

Gemini（Nano Banana）や Seedream でも同じプロンプトで使えます。その場合は「セリフは縦書き」を「セリフは横書き」に変えると文字崩れが減ります。

## ■ ステップ0（画風統一）：3人を同じ画風で描き直した設定画を作る

元の3枚は画風（線・塗り・リアル度）がそれぞれ違うため、最初に ChatGPT に「統一版の設定画」を1枚作らせます。キャラ設定シートを添付して送ってください。

```
添付したキャラクター設定シートの3人を、これから作る漫画の「キャラクター設定画（三面図ではなく全身の立ち姿）」として、1枚の画像に3人並べて描き直してください。目的は3人の画風・線の太さ・塗り・顔の描き方を完全に統一することです。

【画風】フルカラーの日本アニメ調。線は細く均一、影はアニメ塗り（セル塗り2段階）、肌や髪のタッチも3人で同じにする。背景は白。3人の身長差は元画像のとおり（銀地が最も高く、りゅうせいが最も小さい）。

【3人の外見（元画像を忠実に。変えない）】
① 銀地（ぎんじ）：黒髪ショート、黒いうさぎの耳、ネイビーのスーツに白いTシャツ、青いストラップのIDカード、腕時計。胸の名札に「施設長 銀地」と書く。
② りゅうせい：黒髪ショート、丸いくまの耳、ミントグリーンのポロシャツに白いエプロン（肉球ワッペン）。名札に「りゅうせい」と書く。
③ 福田（ふくだ）：明るい茶色のミディアムヘア、とがったおおかみの耳とふさふさの尾、ミントのシャツに白いエプロン、ポケットにウクレレ。名札に「福田」と書く。

【出力】横長の1枚。左から ①銀地 ②りゅうせい ③福田 の順。各人物の足元に名前を日本語で入れる。名札の文字は正確に。
この画像を以降の全ページの「正」の参照にするので、顔立ちが分かる程度に大きく描いてください。
```

## ■ 共通プロンプト（ステップ0で作った統一版の設定画を添付して送る）

```
あなたはプロの漫画家です。添付したキャラクター設定画（3人）の人物・画風をそのまま使って、社内研修用の学習マンガ（全11ページ）を描きます。登場人物はこの3人だけです。
これから私が「ページ○」の指示を1ページずつ送るので、そのたびに漫画1ページ分の画像を1枚生成してください。

【出力仕様】
- 画像は縦長（縦:横 = 3:2）、B5判の漫画ページのイメージ。高解像度。
- 1ページに4〜6コマ。コマ割りとコマの内容は各ページの指示どおりにする。
- 読む順番は日本の漫画と同じ「右から左、上から下」。
- 画風：添付キャラクター画像と同じタッチのフルカラー日本アニメ調。線は細く丁寧、影はアニメ塗り、背景はオフィス・住宅など簡潔に。
  （モノクロで作りたい場合はこの行を「モノクロ、スクリーントーン、Gペンの線画」に置き換える）
- 吹き出し：白地に黒い輪郭の日本の漫画の吹き出し。セリフは縦書きの日本語で、指示した文字を一文字も変えずに入れる。読みやすい太めのアンチック体風。長いセリフは2つの吹き出しに分けてもよい。
- 説明文（ナレーション）は黒い帯の白文字、または角ばった枠で入れる。
- 各ページの上部に、指示された見出し（例：PHASE 1 売主を知る）を黒帯で入れる。
- 効果線・集中線・汗・電球・「！」などの漫画的表現を適切に使う。

【登場人物（毎ページ必ず同じ外見で描く。設定シートの①②③）】
※以下のページ指示では「施設長」＝銀地、「新人」＝りゅうせい、「中堅スタッフ」＝福田のことです。
1. 銀地（ぎんじ）＝シート①。施設長で先輩役。黒髪ショート、頭に黒いうさぎの耳、ネイビーのスーツに白いTシャツ、青いストラップのIDカード、胸の名札に「施設長 銀地」、腕時計。落ち着いていて頼れる雰囲気。表情は基本穏やか、要所で真剣。
2. りゅうせい＝シート②。新人スタッフで新人役。黒髪ショート、頭に丸いくまの耳、ミントグリーンのポロシャツに白いエプロン（肉球ワッペン）、名札に「りゅうせい」。元気で素直、リアクションが大きい。
3. 福田（ふくだ）＝シート③。中堅スタッフで同僚役。女性。明るい茶色のミディアムヘア、とがったおおかみの耳とふさふさの尾、ミントのシャツに白いエプロン（ポケットにウクレレ）、名札に「福田」。明るく気さくで、現地確認や電話の相手役として新人を手伝う。主役2人より出番は少なめ。

【物語の設定】
不動産の買取をしている会社のオフィス。新人のりゅうせいは「売出680万円の中古住宅を400万円で買付を入れたい」案件を抱えている。施設長の銀地が「心情・社会的意義から Evidence（根拠）につなげる価格交渉」の考え方を教える。
会社の事業は「既存の住宅を買い取って改修し、一般的な賃貸住宅を借りることが難しい方にも住める住居（シェアハウス等）として再生する」こと。

【禁止事項】
- キャラクターの服装・耳・髪型・顔を変えない。名札の文字（施設長 銀地／りゅうせい／福田）を変えない。
- 3人の画風・線の太さ・塗りは設定画のまま統一する。
- セリフの改変・要約・追加をしない。英語や意味のない文字を入れない。
- 実在の会社名やロゴを入れない。

準備ができたら「了解しました。ページ1の指示をください」とだけ返してください。
```

## ■ ページ7（PHASE 3〜4）

```
ページ7を描いてください。見出し「PHASE 3 『実現するためにはこの金額が必要』とつなげる」。

【コマ1・上段横長】施設長が指を立てる。横に費用のアイコン群（内装・修繕・設備・水回り・安全面の工事・シェアハウス運営のための工事）。
 セリフ「社会的意義を話して終わりじゃない。次は『それを実現するためには何が必要なのか？』へ話を進める。」
```
