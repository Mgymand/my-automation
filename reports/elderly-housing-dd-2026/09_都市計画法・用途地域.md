## 9-0 結論

1. **3市とも線引き都市計画区域**（加須市の旧北川辺町域 2,090ha のみ非線引き・用途地域なし）。行政区域に占める市街化調整区域の割合は加須 約74%、熊谷 約83%、行田 約83%で、**中古戸建の相当部分が調整区域にある**。【D】
2. **調整区域では、建築工事を伴わない用途変更でも都市計画法43条（開発許可地は42条ただし書）の許可が必要**。延床200㎡以下で建築確認が不要でも、この許可は省けない。【A】
3. **3市の最大の違い：34条11号区域で寄宿舎・共同住宅を認めるのは加須市だけ**。熊谷市・行田市は11号の許容用途から共同住宅・寄宿舎・下宿を除いている。一方、**有料老人ホーム（建築基準法上「老人ホーム」）は別表第2（ろ）項に含まれるため3市とも11号区域で可能性がある**。＝**調整区域では「寄宿舎化」の方が「有料老人ホーム」より立地のハードルが高い場合がある**（熊谷・行田）。【D】
4. 許可権者は3市とも市長（熊谷は施行時特例市、加須・行田は事務処理特例）。【A／D】
5. **分家住宅・農家住宅・自己用住宅（属人性のある許可）は、第三者への売却・賃貸そのものが用途変更として許可の対象**。広告に「分家住宅」「農家住宅」「自己用に限る」とあれば原則見送り。【D】
6. 熊谷市・行田市は2022年の法改正に合わせ、浸水深3m以上・家屋倒壊等氾濫想定区域（熊谷は土砂災害警戒区域も）を11号・12号区域から除外。**熊谷は「除外区域では既存建築物の用途変更ができない」と明示**。加須市は条例改正で適用させず、3m以上の区域も区域内に残している。【D】

## 9-2 市街化調整区域での用途変更：法律の枠組み【A】

- **43条1項**：開発許可を受けた区域以外の調整区域で、建物の用途を変えて29条1項2・3号（農家住宅・公益施設）以外にするには許可が必要。
- **42条1項**：開発許可区域（工事完了公告後）で予定建築物以外の用途に変えるにはただし書許可。用途地域がある区域には適用されない。
- 許可基準（令36条1項3号）：イ＝34条1〜10号相当、ロ＝11号区域内で条例の用途、ハ＝条例で定めるもの（12号相当・既存建物の用途変更）、ホ＝開発審査会。
- 許可不要は、用途変更部分が10㎡以内など（令35条）に限られる。

## 9-6 物件広告の表記から判定する方法【D】

不動産の表示に関する公正競争規約 施行規則7条により、調整区域の土地は「市街化調整区域。宅地の造成及び建物の建築はできません。」の明示が義務。開発許可済み・11号・12号・令36条1項3号ロ・ハ該当のものは「住宅等を建築するための条件」の記載に代えられる。

| 広告の表記 | 意味 | 判定 |
|---|---|---|
| 調整区域文言だけで条件の記載なし | 許可の見込みが示されていない | 原則見送り（例外：線引き前建物） |
| 「11号区域」「既存集落（12号）」「条件：○○」 | 条例区域内 | 加須の11号は寄宿舎も検討可。熊谷・行田は老人ホーム類のみ |
| 「線引き前」「区域区分日前建築」「昭和45年以前」 | 用途が限定されていない | **有望**（ただし用途変更には43条許可が必要。旧耐震に注意） |
| 「既存宅地」 | 旧制度の確認地（制度は2001年廃止、経過措置は2006年終了） | 線引き前建物に準じる【E】 |
| 「分家住宅」「農家住宅」「自己用に限る」「属人」「用途変更に許可要」 | 属人性のある許可 | **見送り寄り**（築20年＋既存集落内か11号区域内のみ再検討） |
| 「開発許可取得」「開発登録簿あり」 | 42条の対象 | 予定建築物を確認し⑤ルートで判断 |
| 「再建築不可」「建築不可」 | 接道義務（建基法43条）等に不適合 | 原則見送り（特殊建築物の県条例の接道規定も要確認） |
| 「43条但書」「43条2項2号許可」 | **建築基準法の接道特例**（都市計画法43条とは別物） | 再建築不可と同様にリスク評価。加須市では43条2項1号認定は「200㎡以内の一戸建て住宅」が対象で、寄宿舎等への転用では2号許可になる可能性（要確認） |
| 「建築条件付」 | 請負契約が条件の土地 | 既存建物取得では通常無関係 |
| 「非線引き」「区域区分なし」 | 加須市北川辺 | 都計法の許可不要。浸水深を必ず確認 |
| 「土砂災害警戒区域」「浸水想定区域」 | 重要事項説明の対象 | 熊谷・行田では用途変更ルートが消えている可能性 |
