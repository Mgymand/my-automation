# 埼玉県・小規模戸建型高齢者住宅事業 法務・開発デューデリジェンス報告書（2026年9月29日時点）

**テーマ**：「毎月3施設出店できる、100〜200㎡木造戸建・9人型モデルを、有料老人ホーム登録制度の下でも適法かつ持続可能にするにはどう再設計すべきか」

**対象地域**：埼玉県 加須市・熊谷市・行田市（周辺市町村への展開を想定）

**作成**：高齢者住宅事業 法務・開発デューデリジェンスチーム（弁護士／行政書士／一級建築士／消防設備士／介護事業コンサルタント／不動産開発責任者／行政協議担当／事業戦略コンサルタント／コンプライアンス責任者の視点で分担調査）

> **重要な注意**
> 本報告書は、2026年9月29日時点で公開されている一次資料（e-Gov法令検索、厚生労働省、国土交通省、総務省消防庁、埼玉県、各市・各消防本部の公開資料等）を可能な限り確認して作成した**調査報告**であり、個別案件についての法的意見書ではありません。登録制度の政省令・条例は未確定の部分が多く、また「有料老人ホームに該当するか」「消防用途」「用途変更の適合範囲」は最終的に所管行政庁が個別の実態に基づいて判断します。採用前には PART 20 の質問集と PART 18 の DD パッケージで**書面照会**を行ってください。

## 確度の凡例（全 PART 共通）

| 記号 | 意味 |
|---|---|
| **A** | 既に成立・公布されている法律・政省令・告示上の確定事項 |
| **B** | 公布済みだが施行日・政省令・告示等が未確定の事項 |
| **C** | 厚労省検討会・審議会等で検討中の案 |
| **D** | 自治体独自基準・行政運用 |
| **E** | 当チームの法的推論 |

結論の強さの分類：**法令上ほぼ明確**／**自治体確認が必要**／**政省令待ち**／**書面照会推奨**／**専門家意見必須**

> **方針決定の反映（2026年9月29日確定）**：訪問介護・居宅介護支援は、グループ会社ではなく**当社と無関係の既存の地域事業者**が指定を受けて提供し、当社グループは指定を持たない（既存事業所は第三者への譲渡又は廃止）。確定した前提と、事業者との関係のルール、既存事業の移行、収支への影響は **PART 24** にまとめた。PART 1〜23 の「グループ」「自社訪問介護」「関連訪問介護」に関する記述は、確定方針の下では「方針どおりに運用されなかった場合（関係者が介護事業者に関与した場合）に生じるリスク」として読むこと。
