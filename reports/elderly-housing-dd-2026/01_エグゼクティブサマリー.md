## 1. 制度変更の現状（何が決まり、何が未定か）

- **法律は成立・公布済み**：「社会福祉法等の一部を改正する法律」（令和8年法律第51号）、2026年6月19日成立・6月25日公布。【A】
- **登録制の施行は「公布から2年以内の政令で定める日」（法定上限 2028年6月24日）で、政令は未制定**。政省令は2026年内に公布予定。【A／B／C】
- **既存ホームには施行後「1年6月以内の政令日」まで猶予**（施行日前に届出をした者に限る）。**「施行まで1年半」という認識は不正確**で、正しくは「施行まで最長約1年9か月＋既存ホームはその後最長1年6か月」。【A＋E】
- **登録対象は「政令で定める要介護状態区分等の者を入居対象とするホーム」**。厚労省案は中重度（要介護3以上に言及）・認知症自立度Ⅲ以上・医療ニーズの者を入居対象とするホームと、中重度になっても住み続けられるホームで、「既存ホームの大半が対象」。**生活保護受給の要介護者を入居対象とする当社の9人ホームは、ほぼ確実に登録対象**。【B＋C＋E】
- 登録基準は国の省令に基づき**埼玉県が条例で定める**（人員は「従うべき基準」、設備は「参酌すべき基準」）。国案は**定員9人以下・戸建（延べ200㎡未満）の特例を維持し、夜間はオンコール可**。ただし**埼玉県の現行指針は夜間常駐（訪問介護員とは別の直接処遇職員）と居室13.2㎡を求めている**。【C＋D】
- 無登録営業は**1年以下の拘禁刑又は100万円以下の罰金（法人も処罰）**。囲い込み対策（関連事業所の利用の条件化・家賃優遇の禁止、ケアマネの独立性、会計の区分経理）が登録要件になる。新しいケアマネ類型「登録施設介護支援」（1割負担）は公布から3年以内に施行。【A＋B＋C】

## 2. 最大のリスク

1. **「何も変えずに続ける」ことが最大のリスク**。現行の収益構造（低家賃＋グループ訪問介護の集中・高利用）は、登録基準・囲い込み対策・2027年度介護報酬改定（集合住宅向け評価の見直し）が狙い撃ちにしている領域そのもの。【B＋C】
2. **埼玉県条例が夜間常駐を求めた場合、9人規模の住宅型は住宅側だけで月約30〜120万円の構造的赤字**（当チーム試算）。国案（オンコール）でも住宅側単体は均衡〜赤字で、自由選択の結果としての介護収入と、職員の時間区分の兼務に依存する。【E】
3. **「名称だけ寄宿舎化」は最悪の選択**。国の通知は「寄宿舎や共同住宅でも」「別法人でも紹介・斡旋で一体的に提供していれば」有料老人ホームとして扱うと明記しており、消防も名称でなく実態で(6)項（スプリンクラー等）を判定する。**施行後に否認されると、経過措置（施行日前の届出者のみ）に乗れず無登録営業になり得る**。【A＋D＋E】

## 3. 寄宿舎転換の核心

- **建築基準法上の「寄宿舎」と老人福祉法上の「有料老人ホームでないこと」は別の判断**。寄宿舎であることは有料老人ホームでないことを何ら保証しない。【A＋D】
- 有料老人ホームから外れる鍵は、**住宅側（一体的なグループを含む）が介護・食事・家事・健康管理を一切供与しないこと**。年齢の割合で外れるという根拠はない。安否確認・見守り・生活相談・緊急時の通報は介護等に当たらない（国の居住サポート住宅解説書・自治体基準）。【A＋D】
- **現在の入居者像（中重度・自力避難困難）のまま非該当型に転換することはできない**。非該当型は「別の顧客層（年齢を問わない自立〜軽度の住宅確保要配慮者）向けの別事業」としてなら成立する。【E】
- 見落としやすい別規制：**生活保護受給者中心の寄宿舎は、有料老人ホームを外れても「無料低額宿泊所」（社会福祉法の事前届出、埼玉県条例：居室7.43㎡以上等）に該当し得る**（基準省令2条：生計困難者限定、被保護者50%以上＋賃貸借以外の契約／密接関係事業者を含む有料サービス）。【A】

## 4. 現実的な選択肢（推奨：二本立て）

| | 主軸① M1 登録対応型 小規模住宅型有料老人ホーム | 主軸② M2 居住サポート住宅型 共同居住住宅 |
|---|---|---|
| 対象 | 中重度の要介護高齢者（生活保護可） | 年齢不問の住宅確保要配慮者、自立〜軽度（生活保護可） |
| 法的位置付け | 老人福祉法の登録有料老人ホーム | 住宅SN法の登録住宅＋居住安定援助計画の市長認定。**有料老人ホームに該当しない**（見守り・つなぎのみ） |
| 物件 | 延べ**200㎡未満**、SP用の水道、1階に車椅子対応居室 | 延べ**145〜199㎡**で専用居室9㎡以上×9（小さい物件は定員6〜8） |
| 消防 | (6)項ロ：SP・自火報・通報装置・甲種防火管理者 | (5)項ロ（自火報・通報の自主設置を推奨） |
| 初期改修費 | 約900〜1,600万円 | 約550〜1,100万円 |
| リードタイム | 物件発見から9〜12か月（県事前相談は着工6か月前〜、登録審査） | 3.5〜5か月 |
| 役割 | 既存ホームの適合化と年数施設の新設 | **月3施設の出店を担う標準モデル** |
| 最大の障壁 | 埼玉県条例の夜間基準 | 物件の面積要件、関連訪問介護との一体性・無低範囲の書面確認 |

**登録が難しい場合**：要介護2以下への切り替えは選べるが、判断は県の条例案が出た時点で施設ごとに行う。要介護2以下が中心の施設は、届出ホームにとどめるより M2 に移すほうが採算を取りやすい。登録しても国の報酬・補助は増えない（PART 3-7）。【E】

補助的に、**無料低額宿泊所＋日常生活支援住居施設（3市に日住ゼロ。福祉事務所と組むクラスター型）**、障害者GH、認知症GH（公募時のみ）を組み合わせる。サ高住・共同住宅化は面積基準で不成立。

**物件の基準（一言）**：市街化区域・浸水3m未満・整形地（旗竿地は寄宿舎不可）・**延べ145〜199.9㎡**（200㎡ちょうどは緩和が使えない）・新耐震・確認済証あり・階段を架け替えずに済む2階建。

## 5. 今すぐやるべきこと（今月）

1. **全施設の自己監査**：未届の有無、夜間の直接処遇職員、要介護3以上の比率と消防設備（SP未設置の(6)項ロ相当は最優先で是正）、住宅スタッフの介助の保険請求、家賃割引の介護連動、契約書の条件条項。
2. **即時停止**：住宅スタッフの介助を訪問介護として請求すること、介護利用と連動した家賃割引、自社介護前提の広告。**未届があれば直ちに届出**（施行日前の届出が経過措置の条件）。
3. **住宅型の新規出店を一時停止**し、M2の標準仕様（プラン・契約書・業務分掌・広告）を確立。M1の新規は登録仕様を満たす案件に限定。
4. **包括照会**：スキーム図・契約書案・業務分掌・広告案を添えて、埼玉県高齢者福祉課（有料老人ホーム該当性）・社会福祉課（無料低額宿泊所の範囲）・3市の建築・消防・福祉事務所に書面照会（PART 20）。
5. 既存入居者のアセスメントに基づき、施設ごとに **Track A（登録適合）／Track B（空室化後にM2へ転換）／Track C（撤退）** を決定（PART 19）。**看板の掛け替えや混在運用はしない**。

## 5-2. 方針決定：訪問介護・居宅介護支援は当社と無関係の事業者で（2026年9月29日確定）

- **確定内容**：介護は既存の地域事業者（当社と資本・役員・親族・資金・人員・拠点・営業のつながりなし）が提供し、**当社グループは訪問介護・居宅介護支援の指定を持たない**。既存のグループ事業所は第三者への譲渡又は廃止。入居者には複数事業者を中立に提示する。
- **結論への影響**：M2 の「関連訪問介護と実質一体」の論点は解消（ストレステスト○）。M1 は住宅単体の採算で判断し、大家モデル（M1-L）を優先検討。以下は確定前に整理した一般論（参考）。

- **効果が出る条件**：別会社が、当社（オーナー・役員・親族を含む）と**資本・役員・実質的な支配・資金・人員・拠点・営業・情報のいずれでもつながっていないこと**。この条件を満たせば、M2（居住サポート住宅型）の最大の論点だった「関連訪問介護と実質一体ではないか」は解消に向かう。【D＋E】
- **やってはいけない形**：名義上の株主・役員を立てて当社が実質的に運営する形。介護保険法は相談役・顧問等の名称を問わず実質的な支配者を「役員」に含めるため、虚偽申請・不正の手段による指定として取消しの対象になり得る。老人福祉法上も「複数法人の一体的経営＝いずれも設置者」と扱われる。【A＋D】
- **経営上の帰結**：介護収入はグループに入らないため、**住宅単体で黒字化できる M2 を主軸に**。M1 は住宅単体では赤字寄り（月−41〜−6万円程度）になるため、**第三者の登録ホーム運営事業者への一括賃貸（大家モデル M1-L）**を含めて再検討する。
- 詳細（独立性の判定基準、してよいこと・いけないこと、指定申請の窓口と期限、既存事業所の譲渡・廃止）は **PART 24**。

## 6. 結論の確度

| 分類 | 内容 |
|---|---|
| **法令上ほぼ明確** | 法律の成立・公布・枠組み、無登録営業の罰則、有料老人ホームの定義（人数要件なし・委託や一体的提供を含む）、無低の範囲（省令2条）、消防(6)項ロの設備、建築の200㎡基準と実体規定の適用、県条例10条（旗竿地） |
| **自治体確認が必要** | 埼玉県の該当性判断（FAQなし）、用途判定（建築・消防）の個別運用、住宅扶助の共同居住での床面積算定、居住サポート住宅の3市の運用、調整区域の許可 |
| **政省令待ち** | 施行日、登録対象の要介護状態区分、省令基準（夜間・面積・特例）、猶予終期、登録施設介護支援の報酬 |
| **書面照会推奨** | M2の有料老人ホーム非該当と関連訪問介護との一体性、M2・M3の無低範囲（ただし書）、M4の有料老人ホームとの二重該当 |
| **専門家意見必須** | 既存入居者の契約変更・住み替え（弁護士）、個別物件の法適合（建築士）、消防設備の設計（消防設備士）、グループ間取引の税務（税理士） |
